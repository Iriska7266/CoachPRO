# Состояние проекта CoachPRO

19 октября 2026 · версия 0.1 · локальная веб-версия на JavaScript

## Принятые технические решения

- JavaScript + React/Express; веб сейчас, мобильные приложения позже — указание владельца.
- PostgreSQL с доступом из pgAdmin. На этом компьютере выбрана локальная установка без Docker.
- Владелец разрешил отправить код в отдельную ветку `codex/web-mvp` репозитория Iriska7266/CoachPRO. Назначение команды отложено. Внешний хостинг приложения не настраивался.
- Сохранение тренировок явное; версии предотвращают незаметную потерю правок.
- Автотекст сводки по правилам, без внешней нейросети. Настройка публикации до/после проверки тренером.
- Автоматическое заполнение исходных полей карточки из новых записей относится к этапу 6 и не реализовано. История измерений и графики обновляются.

## Точка решения о мессенджере

Важные комментарии с уведомлениями уже покрывают опоздание, отмену и отчёт по тренировке. Общий чат позволил бы обсуждать вопросы вне задач и общаться группе, но потребовал бы отдельных правил уведомлений, хранения/удаления сообщений, поиска и модерации. Предложение для первого пилота — использовать существующий канал общения команды, а в CoachPRO оставить комментарии к тренировкам. **Окончательное решение о личном/групповом чате не принято**; этап 5 не объявлен отменённым.

## Практические ограничения версии

- Проверки выполнялись на локальном сервере и вымышленных данных. Продуктовые гипотезы и готовность к публичной эксплуатации пока не подтверждены.
- Офлайн-очередь поддерживает быстрый ввод; не все изменения и файлы.
- Камера/QR и реальная доставка push требуют ручной проверки с разрешениями на целевых устройствах.
- Локальные письма восстановления сохраняются в `.local/mail`. Для доставки нужен SMTP.
- Серверные расписания работают, пока сервер включён. Файлы локальные; резервное копирование и перенос на внешний хостинг пока не настроены.
- pgAdmin — локальный административный инструмент; вход отдельный от приложения. Пароли в `.env`.
- Сводная динамика — эвристика; ручная корректировка доступна. План по дате линейный, конец целевого дня считается в UTC.
