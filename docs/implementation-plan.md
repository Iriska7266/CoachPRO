# План реализации веб-версии

Источники: второй файл пользователя и полный Word-документ, прочитанный из Downloads. Тексты сохранены в docs/source. Сверено с функциями A–J и критериями продукта. Состояние на 19 октября 2026.

Стек: JavaScript для браузера и сервера. Мобильные приложения вне текущего объёма. [x] означает технически реализованный результат, а не завершение всего этапа или одобрение пользователями. [ ] — ожидает участников или отдельной внешней проверки. Приоритеты предварительные: «обязательно» — основа, «желательно» — функции, разрешённые к переносу во втором файле, «потом» — мобильные приложения и чат до решения команды.

Ответственные за разработку, проверку, дизайн и пилот пока не назначены. Наличие технической реализации не означает согласования командой или успешного пилота.

## Вне текущей реализации

- Мобильные приложения — потом, по прямому указанию пользователя.
- Встроенный мессенджер — решение команды после этапа 2; его наличие не предполагается.
- Опросы, утверждение схемы и пилот требуют реальных участников; их нельзя заменить автоматическими проверками.

## Предлагаемые правила работы

- Задачи: идентификатор WEB-этап-номер из этого списка, краткий заголовок, критерий приёмки.
- Ветки: codex/<краткое-описание>.
- Проверка изменений: другой участник проверяет доступы, поведение и результаты тестов; состав команды ожидается.
- Закрывать задачу только после проверки её критерия приёмки; технические и организационные результаты фиксировать отдельно.
