# Проверки CoachPRO

19 октября 2026. Локально: macOS, Node.js 24.19, PostgreSQL 18.4, Chromium встроенного браузера. Вымышленные данные, не реальный пилот.

## Автоматические проверки

- `pnpm check`: синтаксис JavaScript сервера, скриптов и тестов.
- `pnpm test`: **16 пройдено**. Направление цели, достижение/переход цели, плато, ноль, недостаток данных, удалённые значения, границы периода сводки, месячный переход, выполненная задача, линейный план и просроченная цель.
- `pnpm test:integration`: **24 сценария пройдено** на отдельной `coachpro_test` с HTTP API. Авторизация, приглашения, изоляция связей/режимов, скрытые поля и история, конфликты версий, идемпотентность, права параметров, удаление/восстановление, независимые групповые задачи, авторство, важные комментарии, отчёты, публикация сводок, повтор планировщика, метрики и откат, приватность старых сводок, смена аккаунта офлайн-очереди, вложения, выход из связи, защитный заголовок, одноразовый сброс пароля и отзыв сессий.
- `pnpm build`: production-сборка React/Vite успешна.

Тесты не очищают основную базу. Интеграционный тест пересоздаёт public только в базе с суффиксом `_test`. Тестовый пользователь не имеет доступа к разработческой БД. CI-конфигурация подготовлена; запуск на GitHub ещё не выполнялся.

| Сценарий | Результат |

| Переключение того же аккаунта в подопечного | Показана одна собственная связь вместо пяти чужих подопечных |

| Редактирование цели показателя | Число 74 и дата 30.11.2026 сохранены; график показывает ожидаемое значение и опережение плана |

## Исправленные ошибки

| Приоритет | Ошибка | Исправление / проверка |
|---|---|---|
| Высокий | Повтор офлайн-записи мог дублировать результат | Уникальный operation_id + интеграционный тест + отключение сервера в браузере |
| Высокий | Смена аккаунта при очереди могла отправить запись от другого пользователя | Проверка аккаунта на клиенте и client_user_id на сервере, тест |
| Высокий | История/старые сводки могли раскрывать приватные данные | Фильтрация истории и повторная проверка видимости сводок, тест |
| Высокий | Одновременные правки перезаписывали данные | Версии, транзакции и 409, тесты |
| Средний | Некорректное смещение месяца на 31-м числе | Ограничение последним днём месяца |
| Средний | Настройка метрик не имела отката и срока цели | Версии, аудит, восстановление и target_date |
| Средний | pgAdmin отвергал локальный email с .local | Локальное имя входа admin@example.com, вход проверен |
| Средний | Демозамеры могли оказаться позже текущего времени | В новых демоданных дата ограничена текущим моментом |

## Не проверено

Реальная камера/QR, разрешения и доставка Web Push, доставка SMTP, внешнее размещение/HTTPS, Safari/Firefox и реальные телефоны, нагрузка, антивирусное сканирование файлов, восстановление бэкапа. Автотесты не заменяют пользовательскую приёмку. План пилота — `pilot.md`.
